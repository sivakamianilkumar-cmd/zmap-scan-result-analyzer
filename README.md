## ZMap Scan Result Analyzer

A small Python project that analyzes ZMap network scan results.

## Aim
To analyze ZMap scan results and display useful information
about responsive hosts.

## Technologies Used
- ZMap
- Python
- Pandas
- Matplotlib
- Kali Linux

## Features
- Counts responsive hosts
- Finds unique IP addresses
- Displays responsive IP addresses
- Generates a graph

## Project Workflow

ZMap
  ↓
CSV File
  ↓
Python Analyzer
  ↓
Analysis
  ↓
Graph

## How to Run

python3 analyzer.py

## Output

The program displays the number of responsive hosts
and generates a report.png graph.
